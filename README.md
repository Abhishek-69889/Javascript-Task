# JavaScript Task-Based Learning Repository

This repository is a collection of **small JavaScript tasks designed to help you master JavaScript by building and solving things**, rather than only watching tutorials or reading theory.

The idea is simple:

> **Learn JavaScript → Build small things → Make mistakes → Debug → Understand → Repeat.**

Each task focuses on a specific JavaScript concept and gradually increases in difficulty.

## What You'll Learn

By completing these tasks, you will practice:

* JavaScript fundamentals
* Variables and data types
* Operators
* Conditional statements
* Loops
* Functions
* Arrays and array methods
* Objects
* Strings and string methods
* Scope
* Higher-order functions
* Callbacks
* DOM manipulation
* Events and event listeners
* Forms and user input
* Local Storage
* ES6+ features
* Asynchronous JavaScript
* Promises
* `async/await`
* Fetch API
* APIs
* Error handling
* JavaScript concepts used in real-world projects

## How This Repository Works

The tasks are arranged from **beginner → intermediate → advanced**.

Don't try to memorize JavaScript syntax.

Instead, for every task:

1. Understand the requirement.
2. Try solving it yourself.
3. Search your existing knowledge before searching the internet.
4. Debug your errors.
5. Understand why your solution works.
6. Try improving your solution.
7. Move to the next task.

The goal is not to write perfect code on the first attempt.

The goal is to become comfortable with **thinking in JavaScript**.

# The Golden Rule

**Don't copy the solution immediately.**

Try this process:

```text
Read Task
   ↓
Understand Requirements
   ↓
Think About the Solution
   ↓
Write Code
   ↓
Get Errors
   ↓
Debug
   ↓
Understand the Error
   ↓
Improve Your Code
   ↓
Move to Next Task
```

Getting errors is part of the learning process.

For example:

```js
TypeError
ReferenceError
undefined
null
NaN
```

Don't just fix the error.

Understand **why JavaScript produced it**.

# Goal

The goal of this repository is not to collect hundreds of JavaScript exercises.

The goal is to develop the ability to look at a requirement and think:

> **"How can I solve this using JavaScript?"**

By the end of this repository, you should be comfortable taking a small requirement and turning it into a working JavaScript application.
